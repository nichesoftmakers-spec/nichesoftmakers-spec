# 👋 Welcome to Niche Soft Makers (ニッチソフトメーカーズ)

**現場の「名前のない単純作業」を3秒で終わらせる、Windows専用ポータブルGUIソフトウェア開発スタジオ**

ニッチソフトメーカーズでは、動画編集、音響制作、経理帳票、事務データ処理など、日々のワークフローに潜む「地味に時間がかかる単純作業」をワンクリックで解決する実務特化型デスクトップツールを開発・公開しています。

---

### 💎 スタジオ開発ツールの4大特徴

1. **ゼロインストール・環境構築不要**: Pythonのインストールやコマンドプロンプト操作は一切不要。ZIPを解凍してダブルクリックするだけで即起動します。
2. **完全オフライン動作（高セキュリティ）**: 外部サーバーへの通信は一切行いません。社外秘の業務データや未公開の音声・映像素材も漏洩リスクゼロで安全に処理できます。
3. **完全買い切り提供**: 月額サブスクリプションや追加課金は一切ありません。
4. **全ツール無料Lite版あり**: お手元のPC環境での動作や操作感を安心してお試しいただける「無料Lite版（0円）」を全ツールで配布しています。
